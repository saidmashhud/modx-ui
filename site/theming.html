Guide

Theming

Everything the elements draw comes from --mx-* custom properties. Two layers: primitives (a gray scale, the indigo accent, status colours, type, spacing, radii, motion) and semantic tokens (--mx-bg, --mx-text-muted, --mx-accent…) that the themes switch.

Dark, light, auto

Dark is the default. Set data-theme on <html>:

ValueResult
none, darkThe dark theme.
lightThe light theme (text contrast checked by a unit test: muted text 4.5:1, faint 3:1, danger 4.5:1).
autoFollows the system: light while prefers-color-scheme: light, dark otherwise. Live — no reload.
 
import { applyTheme, resolvedTheme } from '@saidmashhud/modx-tokens';

applyTheme('auto');                 // sets data-theme on <html>
resolvedTheme('auto');              // 'dark' | 'light' right now
applyTheme('light', sidebarEl);     // any element: scopes a section

Per section

data-theme works on any element: a light card on a dark page, or a dark one on a light page. Everything inside, overlays included, takes that section’s theme.

data-theme="dark"

Save On

data-theme="light"

Save On

Semantic tokens

The swatches below are live: switch the theme at the top of the page.

TokenUsed for
--mx-bgThe page.
--mx-surface -raised -overlayFields, dialogs, popovers (each a step up).
--mx-textAaPrimary text.
--mx-text-secondaryAaBody text, list rows.
--mx-text-mutedAaLabels, hints — any text that is read (4.5:1).
--mx-text-faintAaIcons, separators, native placeholders only (3:1).
--mx-border -strongHairlines, field borders.
--mx-accentThe one accent: primary buttons, selection, focus.
--mx-accent-textAaLinks and accent text on the page ground.
--mx-danger --mx-success --mx-warningStatus.
--mx-focus-ringEvery :focus-visible.

Your brand

Override tokens after tokens.css. Keep the light block in step if you support both themes: semantic tokens are re-declared there.

:root {
  --mx-accent: #0f766e;               /* primary buttons, selection */
  --mx-accent-hover: #115e59;
  --mx-accent-text: #5eead4;          /* links on the dark ground */
  --mx-font-sans: "IBM Plex Sans", system-ui, sans-serif;
  --mx-radius-md: 6px;
}
:root[data-theme="light"] { --mx-accent-text: #0f766e; }

One component

Each element documents its CSS parts and custom properties on its page (from the manifest). Parts style the inside from outside the shadow root:

mx-button.cta::part(button) { border-radius: var(--mx-radius-full); }
mx-input.search::part(control) { background: var(--mx-bg-sunken); }
mx-command-list { --mx-list-max-height: 480px; }
mx-toast-region { --mx-toast-offset: 56px; }   /* above a bottom bar */

The kit has no monospace face: figures that must line up use font-variant-numeric: tabular-nums on the sans.
