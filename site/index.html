Web components for apps that keep working offline.

Three packages

PackageWhat it is
@saidmashhud/modx-uiThe mx-* elements: buttons, fields, pickers, overlays, navigation, display, a safe Markdown renderer. Ships custom-elements.json.
@saidmashhud/modx-tokensCSS custom properties: a gray scale, one indigo accent, status colours, type, spacing, radii, motion; data-theme for dark, light and auto.
@saidmashhud/modx-storeStore and selectors on RxJS, immutable tables, SyncEngine (bootstrap, SSE, optimistic writes, offline queue), query helpers, a router, OT.

What it is careful about

  • Forms. Inputs, selects, date pickers, switches and buttons are form-associated: they submit, validate and reset inside a plain <form>. Forms
  • Keyboard and screen readers. Every element is checked with axe-core in both themes, in three browser engines.
  • Right to left. Logical CSS throughout; overlays, arrow keys and directional icons follow the nearest dir. i18n and RTL
  • Phones. Menus become bottom sheets, dialogs go full screen, touch targets grow to 44 px, the keyboard is tracked.
  • Lost answers. Every write carries an idempotency key that survives reloads, so a retry is never applied twice. Store and SyncEngine
