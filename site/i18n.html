i18n and right-to-left

The kit’s own words, its date locale and its first day of the week come from one object, kitStrings. Layout and keys follow the writing direction of wherever an element sits.

Strings and locale

Call setKitStrings() at startup — or any time later: every mounted element re-renders with the new words, and dates reformat. onKitStrings() tells your own code.

import { setKitStrings, onKitStrings } from '@saidmashhud/modx-ui';

setKitStrings({
  locale: 'ru-RU', weekStart: 1,            // dates, month names, typed-date order
  search: 'Поиск…', noResults: 'Ничего не найдено', select: 'Выберите…',
  pickDate: 'Выберите дату', today: 'Сегодня', clear: 'Очистить',
  close: 'Закрыть', dismiss: 'Скрыть', remove: 'Удалить', loading: 'Загрузка',
  breadcrumb: 'Навигация', valueMissing: 'Заполните это поле.',
});
const off = onKitStrings((s) => document.documentElement.lang = s.locale);

The date picker reads typed dates in the locale’s order (11/21/2026 in en-US, 21.11.2026 in ru-RU) and ISO 2026-11-21 everywhere; its hint is derived from the locale unless dateFormatHint says otherwise. Month names in headings use the standalone (nominative) form.

Right to left

Put dir="rtl" on <html> or on any section. The elements read the direction that applies to them — the nearest dir, across shadow roots, or CSS direction — so one page can mix both.

WhatIn RTL
LayoutLogical properties everywhere (padding-inline, inset-inline-end, border-inline-start…).
Popovers, selects, pickersbottom-start lines up with the anchor’s right edge; right-start submenus open to the left. openPicker() carries the anchor’s direction to the popover it mounts in <body>.
ToastsBottom left (the inline end).
SwitchOff on the right, on at the left.
Arrow keys← and → are mirrored in the calendar, the month grid and mx-segmented: → goes to the previous item.
IconsChevrons, arrow-left, arrow-up-right, undo and redo are mirrored; no-mirror keeps one as drawn.
 
import { directionOf, inlineStep, position } from '@saidmashhud/modx-ui';

directionOf(el);                       // 'ltr' | 'rtl', as the element sees it
inlineStep(event.key, directionOf(el)); // ArrowRight → 1 in LTR, -1 in RTL
position(panel, anchor, 'bottom-start'); // logical; pass a 5th argument to force a direction

Mirroring of icons uses the :dir() selector, which follows dir attributes. If you set direction with CSS only, keys and positions still follow it, but put dir on the root too so icons turn.
